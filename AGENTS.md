## Project

This project is Wisp, it's a Rust cross-platform alternative to wallpaper engine.

## Style
- Comments should describe reasons for code, never the code itself.
- Code should be clean and readable, with nice detailed names.
- Code should be reused as much as possible.
- Do only the task requested, if other tasks are necessary to complete that task, do those, but do not scope creep and do not veer off course.

## Behaviour
- Commit often, but never push.
- Create tests wherever failure seams are introduced.
- Tests for one-off usecases are permitted, but must be deleted thereafter.
- Ensure that code you write is auditable by the agent. The agent must be able to launch, interact with, and use the functionality of the application for testing purposes. 
- Do not change AGENTS.md, do not change README.md. For artifacts, you are welcome to add them to the gitignored agents/ directory at the project root.
